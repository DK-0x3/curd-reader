# Разработка Curd Reader

Текущие результаты, ограничения и контекст: [WORKLOG.md](WORKLOG.md).

## Рабочий цикл

1. `npm ci` — установить закреплённые зависимости.
2. `npm test` — регрессионные проверки, включая настоящий EPUB и PDF.
3. `npm run lint` — статическая проверка.
4. `npm run deploy` — собрать, сохранить прежние файлы, установить и сверить сборку в ObsidianVault.
5. Перезагрузить Curd Reader в Obsidian и проверить книгу. После изменения обновить WORKLOG.md.

Другой vault: `npm run build`, затем `node scripts/deploy.mjs /path/to/vault`.
Скрипт рассчитан на стандартную папку `.obsidian`; при нестандартном configDir нужно адаптировать путь.

## Установка

Место: `~/Documents/ObsidianVault/.obsidian/plugins/curd-reader`.
Устанавливаются только `main.js`, `manifest.json`, `styles.css`.
Пользовательские данные не заменяются; предыдущие устанавливаемые файлы лежат в `.local/plugin-backups`.
PDF worker, шрифты, CMap и декодеры встроены в main.js; отдельный каталог pdf-assets больше не нужен. Сборка проверяет ожидаемые места подстановки ресурсов в worker, чтобы обновление PDF.js не сломало офлайн-поставку молча.

В рабочем ObsidianVault до миграции сохраняется установка `elton-reader-books`: для её проверки обновляются main.js/styles.css с резервной копией, без замены старого manifest и data.json. Это отличается от новой установки Curd Reader через стандартный deploy-скрипт; не включать обе версии одновременно.

## Мобильная версия 1.0.1

Описание релиза: [RELEASE-1.0.1.md](RELEASE-1.0.1.md), описание коммита: [COMMIT-1.0.1.md](COMMIT-1.0.1.md). `npm run release:prepare` создаёт архив и SHA256SUMS.txt в `dist/1.0.1/`.

Профили phone/tablet/desktop обязательны: applyDeviceProfile переносит прежние настройки, captureDeviceProfile сохраняет активный профиль. Пути и данные книг остаются общими. При сохранении перечитываются остальные профили с диска; это не заменяет разрешение конфликтов внешней синхронизации.

Мобильные тапы обрабатываются в capture-фазе PointerEvent с fallback на touchend, без двойного переключения от синтетического click. Двойной тап не используется. На больших EPUB мобильная модалка выполняет дополнительный проход раскладки с повторным использованием DOM до восстановления позиции. Автоматические тесты не воспроизводят Android WebView: первое открытие проблемной книги и взаимодействие с панелями требуют живой проверки.

## Адреса и данные

Старые `block` — индексы P,H1–H4. `readerBlocks` сохраняет этот порядок, добавляя новые типы в конец. Геометрия и порядок чтения должны учитывать DOM, а не числовое сравнение расширенных адресов.
Новые записи содержат резервный anchor id/текст. JSON чтения находится в dataFolder или booksFolder, иначе в корне vault. Очереди сохранения не обеспечивают атомарность конфликтов внешнего сервиса синхронизации.
Ключ ИИ хранится через SecretStorage (Obsidian 1.11.4+). На старых версиях запись ключа в открытый JSON запрещена.


## Виртуальные папки и содержание (3.1.4)

`src/library-model.js` — проверяемая модель структуры, глубина до 5, операции, миграция старых категорий, объединение при смене места данных. `reading-library.json` — текстовый файл в vault; физические книги не перемещаются. Корень показывает папки верхнего уровня и книги без привязки; «Все книги» позволяет увидеть весь vault.

`src/toc-tree.js` — дерево оглавления с ленивым созданием вложенных строк, поиском, порционной отрисовкой и измерением видимых строк. При изменении раскладки меняется Paginator._layoutVersion; сбрасывается индекс блоков и устаревают номера разворотов. Не кэшировать индекс во время незавершённой вставки DOM.

Регрессионные проверки этой итерации: `tests/library-toc.test.mjs`. При изменении глобальных настроек проверять также расширенные кнопки без view.file: прокси библиотеки применяет параметры ко всем открытым читателям.

## Настройки и история (3.1.6)

Историю рисует единый `renderReadingHistory(view, host, {onReturn})`; у модалки собственный host. `readingPosition` берёт фактический блок читалки, а при незавершённой загрузке — сохранённый прогресс. `removeReadingHistory` удаляет выбранный объект; `clearReadingHistory` сохраняет позицию и очищает только историю данной книги. Не создавать manual-точки внутренними вызовами настроек: saveNow предназначен для явного сохранения.

В дереве оглавления сохранять DOM-узлы между раскрытиями и высоту бейджа до измерения номера разворота: восстановление одного scrollTop не устраняет смещения из-за изменения высоты текста.
