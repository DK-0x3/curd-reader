## Итерация 3.1.4 — оглавление и библиотека (10 октября 2026)

Запрос: ускорить открытие содержания большой книги, добавить обновление и общие настройки на главную, заменить категории виртуальными папками до пяти уровней.

### Реализовано

- Оглавление стало деревом: сначала только основные пункты, вложенные строки создаются при раскрытии. Поиск показывает совпадения вместе с родителями; «Свернуть всё» возвращает к верхнему уровню. Раскрытие сохраняется при повторном открытии панели той же книги.
- Устранён повторный обход всех абзацев для каждого пункта содержания. Paginator кэширует индекс блоков до следующей сборки раскладки. Номера разворотов вычисляются только для видимых строк и кэшируются до перевёрстки; длинный плоский список добавляется порциями по 60 строк.
- В шапке библиотеки добавлены «Обновить книги», «Настройки чтения» и «Создать папку». Обновление заново сканирует vault и читает прогресс, выделения и структуру библиотеки; изменённые обложки проверяются по прежнему механизму mtime/size.
- Общие настройки доступны без книги. Изменения применяются к открытым читалкам; проверены также расширенные кнопки листания, выравнивания и положения текста. При смене режима чтения сохраняется текущий блок открытых книг.
- Категории убраны из интерфейса. Папки представлены карточками в галерее; доступны создание, переименование, перемещение, удаление, навигация по цепочке родителей. Книги помещаются через меню ⋯ или перетаскивание карточки. Есть «Все книги», глобальный поиск и фильтр состояния чтения.
- Ограничение — пять уровней папок, не считая главную библиотеку. Циклы, шестой уровень и одинаковые имена в одном родителе отклоняются до записи. Выбор места перемещения скрывает собственное поддерево и слишком глубокие назначения.
- Физические книги собираются со всего vault и остаются на своих местах. Настройка booksFolder теперь обозначает место импорта и резервное место данных, а не ограничение поиска книг.
- Старые ручные категории bookTags однократно превращаются в корневые виртуальные папки. Несколько старых категорий сохраняются как несколько вхождений книги, пока пользователь не выберет ей одну папку. Автоматические категории физических каталогов не создаются.
- Удаление виртуальной папки удаляет её поддерево и привязки; книги без других вхождений возвращаются на главную. Удаление физической книги остаётся отдельным действием.

### Данные и сохранность

Структура хранится в текстовом `reading-library.json`: `version: 1`, `folders: [{id, name, parentId}]`, `books: {"путь/книги.epub": ["id папки"]}`, `migratedLegacyTags`. Корень обозначается пустым parentId; книги без папки не записываются в books. Файл находится в dataFolder, иначе booksFolder, иначе корне vault, включён в восстановительные снимки и перенос данных.

Каждая операция выполняется последовательно: перечитать JSON → применить изменение → проверить структуру → записать → обновить память. Повреждённый JSON не заменяется пустой библиотекой. Смена папки данных объединяет структуры по полному пути виртуальных папок; ожидающие операции продолжаются уже по новому пути. Переименование физических книг переносит их привязки. Межустройственные конфликты внешней синхронизации по-прежнему не являются транзакционными.

На телефоне убран backdrop-filter у кнопок, чтобы избежать артефактов композиции при прокрутке. Синяя плавающая кнопка принадлежит интерфейсу Obsidian и не изменяется плагином.
- Emoji папок заменены одним SVG folder-open на всех устройствах. Цвет берётся из --interactive-accent текущей темы Obsidian, независимо от темы чтения и набора emoji ОС. В проверке библиотеки проверяется наличие векторной иконки вместо emoji.
- Сборка остаётся локальной 1.0.1. Перекрытия внешнего интерфейса должны быть подтверждены повторной проверкой на реальном телефоне; автоматические проверки не воспроизводят мобильный WebView и его тему.

### Мобильная читалка: плавающие панели и открытие большого EPUB

- Пользователь сообщил о пустой книге «48 Законов власти — Роберт Грин», EPUB, Android. Файл из ObsidianVault проверен через настоящий epubjs: 18 разделов, 21 072 абзаца, 52 изображения, 449 пунктов содержания; извлечение успешно. Проблема не воспроизведена на реальном Android, поэтому причина не считается доказанной.
- Для очень широких книг на мобильных устройствах (полоса страниц более 16 384px) перелистывание использует позиционирование left вместо translate3d/will-change:transform. Это убирает необходимость композиции всей книги в огромный GPU-слой. Анимация перехода у таких книг отключена; сохранение позиции и геометрия страниц прежние. Полная виртуализация пока отсутствует.
- Область текста в мобильной модалке занимает всю доступную высоту; панели расположены поверх неё. Сверху: назад, таймер по центру при включении, сохранение позиции, обновление. Снизу: настройки, поиск, заметки/выделения, содержание; ниже страницы и процент. Свайпы перелистывают. Тап по тексту скрывает/возвращает панели без перевёрстки; ссылки, картинки, выделения, активное выделение текста и клик после свайпа исключены.
- Устранена ошибка открытия мобильного поиска: панель find теперь получает er-panel-open. Открытие боковой панели возвращает кнопки.
- Ошибка загрузки немедленно снимает er-booting/veil, показывает причину и кнопку повтора; пустое извлечение больше не считается успешным открытием.
- Добавлены проверки полноценного DOM читалки, реального FB2 через загрузчик и paginator, переключения панелей, открытия поиска и отображения ошибки при сбое раскладки; отдельная проверка смещения большой страницы без transform. Проверка на конкретном Android остаётся необходимой.

### 2026-10-11 — отдельные настройки устройств, жесты и отступы

- Профили телефона, планшета и компьютера стали обязательными. Разделены все пользовательские предпочтения, включая таймер/цель и журнал времени, режим/анимацию чтения, язык, оформление, перевод/AI-параметры, параметры заметок и экспорта. Физическая папка книг, папка данных, связи/обложки книг, признаки миграций и SecretStorage остаются общими данными или собственным хранилищем устройства, а не профилем интерфейса.
- При первой загрузке старые настройки копируются в отдельные профили с сохранением прежних perDevice-значений. Объекты профилей копируются независимо. При сохранении перечитываются профили других устройств, чтобы изменение телефона не перезаписывало последний профиль ПК. Одновременные конфликты внешней синхронизации всё ещё зависят от её механизма.
- На Android короткий touchend обрабатывается прямо, повторный click после него игнорируется. Центр скрывает/возвращает панели через класс и hidden; стили темы не могут сделать скрытые панели видимыми. Края при «По клику» симметрично вызывают prev/next, включая режим прокрутки. Прокрутка, свайп, выделение, картинки и ссылки не считаются центральным тапом.
- Добавлен ползунок «Боковые отступы текста» в настройках чтения телефона: 0–48px, по умолчанию 16px. Перевёрстка сохраняет положение, отступы сверху/снизу не зависят от бокового значения; ограничение maxLineCh не увеличивает мобильные поля.
- Добавлены проверки жестов touchend/click, обоих краёв в scroll-режиме, миграции и сохранения профилей, независимости журнала/таймера и ползунка с повторной раскладкой. Живая проверка конкретного Android остаётся за пользователем. Изменения входят в локальную 1.0.1, новый GitHub-релиз не публикуется автоматически.

### Повторная проверка EPUB с полноэкранной обложкой

- Подтверждена ошибка кнопки обновления: refresh-cw отсутствовал в собственном наборе SVG. Мобильная кнопка использует существующий rotate-ccw; наличие SVG проверено тестом.
- У EPUB первой страницей является изображение обложки. Старый обработчик открывал lightbox по одному тапу, а общий обработчик скрытия исключал img. Теперь один тап по изображению обрабатывается как тап страницы; увеличение — двойной тап. Активное выделение проверяется только внутри этой читалки, а не в других частях документа. Для короткого touchend длительность длинного нажатия сверяется с timestamp событий, чтобы задержка основного потока не превращала короткий тап в долгий.
- Первичная раскладка ожидает decode изображений с общим ограничением 2.5 секунды перед измерением. На телефоне позиционирование без GPU-трансформации применяется с момента создания потока, до первого расчёта числа страниц; ранее первый гигантский слой мог создаваться ещё до защитного переключения.
- Paginator запоминает ширину и высоту фактической раскладки. Мобильный ResizeObserver сравнивает обе величины и исправляет раскладку после изменения размера модального окна, включая его первое появление. Ранее учитывалась только ширина, а размер после загрузки мог скрыть несовпадение первоначальной раскладки.
- Всего 61 проверка: дополнены тап по обложке, SVG обновления, ожидание decode до измерения и отсутствие transform с первого построения. ESLint: 0 ошибок, 22 предупреждения. Причина исходного пустого экрана не воспроизведена на самом Android; требуется повторное открытие этой книги на устройстве после обновления.

### Повторное исправление переключения панелей по тексту

- По запросу пользователя полностью удалён мобильный обработчик dblclick и увеличение изображений двойным тапом.
- Переключение панелей теперь обрабатывает touch pointerdown/move/up в capture-фазе на contentEl. Обработчики вложенного текста, которые останавливают распространение событий, не блокируют это касание. Старый touchend используется только без PointerEvent; последующий синтетический click подавляется, чтобы не переключать панели второй раз.
- Оставшееся выделение внутри читалки больше не запрещает короткие тапы постоянно: снимается выделение и закрывается его popup, затем переключаются панели. Длинное нажатие и движение пальца сохраняют поведение выделения/прокрутки. Координаты краёв ограничены видимой шириной экрана, а не возможной шириной потока большого EPUB.
- Добавлена регрессия: вложенный span с stopPropagation на pointerup и активным выделением; скрытие/возврат панелей, отсутствие двойного переключения от click, отсутствие реакции на прокрутку и отсутствие lightbox от dblclick. Всего 62 теста, 0 ошибок ESLint и 22 прежних предупреждения.
- Сам конкретный Android недоступен для воспроизведения: механизм проверен автоматически, исходная причина на телефоне не объявляется доказанной. Сборка и ZIP обновлены, main.js/styles.css установлены в существующий elton-reader-books в ObsidianVault с резервной копией.

### Большой EPUB по-прежнему требует обновления при первом открытии

- Пользователь подтвердил: предыдущие изменения не устранили пустой экран при первом открытии «48 Законов власти» на Android, кнопка обновления показывает книгу. Причина на реальном устройстве всё ещё не воспроизведена.
- Кнопка обновления повторяет раскладку уже извлечённой книги, без повторного чтения EPUB. Мобильная читалка теперь автоматически выполняет этот дополнительный проход для EPUB с HTML более 250 000 символов, после двух кадров с видимым потоком под непрозрачной загрузочной завесой. Проход переиспользует DOM; восстановление сохранённого блока/процента выполняется после него. Обычное обновление во время загрузки блокируется, поэтому завершающий проход встроен непосредственно в загрузку.
- Удалён безусловный таймер, снимавший завесу через три секунды даже до окончания раскладки. Она снимается после завершения; ошибки сохраняют видимое сообщение и возможность повторить открытие.
- Добавлена проверка первого открытия большого EPUB: завершающая раскладка выполняется при активном флаге загрузки, до восстановления позиции. Проверка имитирует необходимость второго прохода, а не настоящий Android WebView. Подтверждение результата на устройстве остаётся необходимым; полного устранения исходной причины не заявляем.
- Контекст продолжения: локальная версия 1.0.1, опубликованный релиз 1.0.0 не изменяем. Обновляем сборку, архив и существующую установку elton-reader-books в ObsidianVault, сохраняя manifest и данные пользователя.
- Проверено: 63 теста проходят; ESLint — 0 ошибок, 22 прежних предупреждения. Сборка и ZIP 1.0.1 готовы. main.js/styles.css установлены в хранилище с резервной копией и проверены побайтовым сравнением.
